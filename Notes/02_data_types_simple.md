# SQL Data Types — Simple Notes

## Numeric
- INTEGER: Pure number (1, 100, 5000)
- NUMERIC: Exact decimal, use for money (999.99)
- FLOAT: Fast but approximate, NOT for money

## String
- CHAR: Fixed length, for country codes (IN, US)
- VARCHAR: Variable length, for names/emails  
- TEXT: Unlimited, for descriptions

## Date
- DATE: YYYY-MM-DD format

## Boolean
- TRUE or FALSE only
