# 📌 SQL Cheat Sheet

## SELECT
- `SELECT * FROM table;` — All columns
- `SELECT col1, col2 FROM table;` — Specific columns

## WHERE
- `WHERE col = value` — Equal
- `WHERE col > value` — Greater
- `WHERE col BETWEEN x AND y` — Range
- `WHERE col IN (v1, v2)` — List match
- `WHERE col LIKE 'A%'` — Pattern (starts with A)

## ORDER BY
- `ORDER BY col ASC` — Ascending
- `ORDER BY col DESC` — Descending

## LIMIT
- `LIMIT n` — Restrict to n rows
